Bem-vindo ao Curso Técnico em Informática

O Curso Técnico em Informática prepara estudantes para atuar no desenvolvimento de sistemas, manutenção de computadores e outras áreas da tecnologia.

Sobre o curso

Objetivo

Desenvolver conhecimentos teóricos e práticos para que os alunos possam criar programas, desenvolver páginas web, trabalhar com bancos de dados e realizar manutenção de computadores.

O que você vai aprender?

  • Lógica de programação
  • Desenvolvimento web
  • Banco de dados
  • Redes de computadores
  • Programação
